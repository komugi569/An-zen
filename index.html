詐欺の4ステップ

ほとんどの被害は、この順番で進みます。

  1. 接点

    SNS広告やDMから、LINEグループへ誘導されます。
    有名人の写真や名前が、無断で使われていることもあります。

  2. 信用づくり

    グループには多数の「サクラ（仲間役）」がいて、「儲かった！」「先生のおかげです！」と全員で盛り上げます。
    あなたを「乗り遅れたくない」気持ちにさせるための演出です。

  3. 誘導・送金

    アプリや偽サイトで、うその利益を見せて振込を促します。
    画面の数字は作り物です。

  4. 破綻

    出金しようとすると、「手数料」や「税金」を追加で請求され、最後は連絡が取れなくなります。
    払っても、お金は戻りません。

危険サインのチェックリスト

ひとつでも当てはまったら、お金を動かす前に止まってください。

  • サイン1：「先生」を持ち上げる書き込みが多い

    グループ内で「先生」「アナリスト」と呼ばれる人物を、何人もがほめ続けています。

  • サイン2：振込先が個人名義、または無関係な法人名義

    投資会社と関係のない名前の口座は、詐欺を疑ってください。口座名義は毎回変わることもあります。

  • サイン3：出金に「手数料・税金を先に振り込んで」と言われる

    これは典型的な詐欺の請求です。払わずに、相談窓口へ連絡してください。

  • おまけ：「今日まで」「あと3名」と急がされる

    考える時間をなくすための決まり文句です。

今すぐできる防犯策：LINEの設定

知らない人とつながる入口を、先に閉じておきましょう。1分で終わります。

  1. 1. 設定（歯車マーク）を開く

    LINEの「ホーム」画面の右上にある歯車マークをタップします。
    プロフィール
    設定

  2. 2. 「友だち」を選ぶ

    設定の一覧から「友だち」をタップします。
    アカウント
    友だち
    トーク

  3. 3. 2つの項目をオフにする

    「友だち自動追加」と「友だちへの追加を許可」をオフにします。
    友だち自動追加
    友だちへの追加を許可

  4. 4. ID検索を制限する

    設定の「プライバシー管理」を開き、「IDによる友だち追加を許可」をオフにします。
    プライバシー管理
    IDによる友だち追加を許可

※アプリの更新で、項目名や場所が変わることがあります。見つからないときは、設定画面の検索で「友だち」や「ID」を探してください。

対処法・相談窓口

3つの鉄則

  • 追加送金は絶対にしない。手数料を払っても、お金は戻りません。
  • 証拠を残す。やり取りのスクリーンショットや振込明細を保存します。相手のアカウント名やURLも控えてください。
  • すぐに相談する。恥ずかしいことではありません。だまされるのは、手口が巧妙だからです。
